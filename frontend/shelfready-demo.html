How it works

Five stages, each a re-runnable worker

A rule or glossary change re-runs only the affected stage — not the whole catalogue.

01

Ingest & enrich

Map feeds to one canonical schema. Extract attributes with source + confidence. Flag image/supplier conflicts.

02

Generate

Claude writes structured JSON — title, bullets, description, keywords, alt text — localised per market, grounded in approved facts.

03

Validate & repair

Deterministic checks + claim grounding + a second-model review. Failures are fed back for up to three repairs.

04

Images

Resize and normalise to each channel's spec; strip overlays; alt text per language; escalate genuinely low-res assets.

05

Review & learn

Risk-routed items go to a reviewer with source beside copy. Edits update the glossary — no model retraining.
